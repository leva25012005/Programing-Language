# C++20: Bộ 4 Tính Năng Khổng Lồ ("The Big Four") & Các Cải Tiến Đáng Giá

C++20 mang đến bộ 4 tính năng khổng lồ (được gọi là **"The Big Four"**) giúp giải quyết triệt để những điểm yếu lâu đời nhất của C++ về thời gian biên dịch, xử lý Template và lập trình bất đồng bộ.

---

## 1. Bộ Bốn Khổng Lồ ("The Big Four")

### 1. Concepts (Khái niệm & Ràng buộc Template)

Trước C++20, khi bạn viết Template và truyền sai kiểu dữ liệu, trình biên dịch sẽ "xả" ra hàng trăm dòng lỗi cực kỳ khó đọc. **Concepts** cho phép bạn đặt điều kiện rõ ràng cho kiểu dữ liệu truyền vào Template.

- **Lợi ích:** Báo lỗi chính xác ngay lập tức, code tự giải thích logic (_self-documenting_), và không còn những đoạn thông báo lỗi dài ngoằng.
- **Ví dụ:** Quy định hàm này chỉ nhận kiểu số (`std::integral`).

```cpp
template <typename T>
requires std::integral<T> // Chỉ chấp nhận T là số nguyên
T add(T a, T b) {
    return a + b;
}
```

---

### 2. Modules (Đổi mới hệ thống Module)

Sau hơn 30 năm phụ thuộc vào các file `#include` (_Header files_) gây tốn thời gian biên dịch và dễ đụng độ tên biến, C++20 chính thức giới thiệu **Modules** (sử dụng từ khóa `import`).

- **Lợi ích:**
  - **Tăng tốc độ biên dịch** lên gấp nhiều lần (do không phải đọc đi đọc lại file header).
  - **Tránh lây nhiễm Macro** hoặc đụng độ tên hàm/biến giữa các thư viện.
- **Cú pháp:** `import std;` _(thay vì hàng chục câu lệnh `#include <iostream>`, `#include <vector>`, ...)_.

---

### 3. Coroutines (Lập trình Bất đồng bộ)

C++20 hỗ trợ chính thức **Coroutine** — các hàm có thể tạm dừng (_pause_) thực thi và tiếp tục (_resume_) sau đó mà không làm đóng băng toàn bộ luồng (_Thread_) chính.

- **Lợi ích:** Giúp việc lập trình xử lý tác vụ ẩn (như tải file, đọc database, lập trình Game) trở nên dễ viết và dễ đọc hơn rất nhiều nhờ các từ khóa như `co_await`, `co_yield`, `co_return`.

---

### 4. Ranges Library (Thao tác Dữ liệu kiểu Pipeline)

Thư viện `<ranges>` cho phép bạn thực hiện các thao tác lọc, biến đổi dữ liệu trên Container (`vector`, `list`) bằng cú pháp đường ống (pipe operator `|`) cực kỳ ngắn gọn, tương tự như trong C# LINQ hay Python.

```cpp
std::vector<int> nums = {1, 2, 3, 4, 5, 6};

// Lọc số chẵn, sau đó bình phương lên
auto result = nums
    | std::views::filter([](int n) { return n % 2 == 0; })
    | std::views::transform([](int n) { return n * n; });
```

## 2. Những Cải tiến Đáng giá Khác

Bên cạnh **"The Big Four"**, C++20 còn bổ sung rất nhiều công cụ ngọt ngào giúp việc viết code hằng ngày trở nên dễ dàng:

- **Toán tử Tàu vũ trụ (`<=>` - Spaceship Operator):** Giúp tự động tạo ra tất cả các phép so sánh (`<`, `>`, `<=`, `>=`, `==`, `!=`) chỉ với một dòng code duy nhất.
- **`std::format`:** Định dạng chuỗi theo phong cách Python (dùng `{}`), thay thế cho cách viết `std::cout` cồng kềnh hoặc `printf` không an toàn.
  ```cpp
  std::string msg = std::format("Xin chào {}, bạn {} tuổi!", "Nhân", 21);
  ```
- **Designated Initializers:** Khởi tạo struct bằng cách chỉ định rõ tên trường dữ liệu (giống ngôn ngữ C).
  ```cpp
  struct Point { int x; int y; };
  Point p{.x = 10, .y = 20}; // Rõ ràng và tránh nhầm vị trí
  ```
- **`std::jthread`:** Luồng dữ liệu cải tiến, tự động hủy/kết thúc (_auto-join_) khi ra khỏi phạm vi hàm, giúp tránh trôi luồng gây crash ứng dụng.
